NICU Dose Calculator 🏥

A professional dose calculator for Neonatal Intensive Care Units (NICU) with full Arabic RTL support.

Features ✨

10 Medications: Comprehensive drug database including Amoxicillin, Gentamicin, Caffeine, Colistin, Tigecycline, Meropenem, Dopamine, and Dexmedetomidine
Arabic RTL Support: Full right-to-left layout for Arabic text
3-Screen Navigation: Patient info → Drug selection → Results
Professional Medical UI: Clean, intuitive interface with blue/teal gradients
Accurate Calculations:
Colistin with proper formatting (e.g., "150,000 IU")
Unit conversions (mcg → mg when needed)
Time multipliers for continuous infusions
Smart Formatting:
Whole numbers without decimals
Decimal values with 1 decimal place
Arabic numeral input support (٠-٩)
Safety Features:
Mandatory safety disclaimer
Telegram contact link to pharmacy team
Responsive Design: Works beautifully on desktop and mobile
